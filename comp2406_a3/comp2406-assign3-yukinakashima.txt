I had loaded the databases with numerous different valid text files with varying empty answers using submitdemo. In which the query above showed a result of 2.

This then moved to executing multiple COUNT functions with labelled columns. Since again I was aware of what I wanted but was unaware of the tool name, I 
googled "sqlite specifying column names for result". Then sure enough, after reviewing the results, the fourth result, namely, 
https://www.prisma.io/dataguide/sqlite/basic-select, had a section explaining the uses of the AS keyword. This led to the query below,

    SELECT 
        COUNT(*) FILTER (WHERE q1 = '') AS empty_q1,
        COUNT(*) FILTER (WHERE q2 = '') AS empty_q2,
        COUNT(*) FILTER (WHERE q3 = '') AS empty_q3,

Lastly, I added a single text file with all whitespace answers, where I realized whitespaces were not counted. Since the question specified any number of 
whitespaces, I thought of deleting all spaces to make them '' before counting. This was where I was reminded of the trim function in JavaScript from using 
strings and regualr expressions at the beginning of the term in this course. I googled if the trim function was a thing in sqlite, and sure enough it was. 
Using the resources from https://www.sqlitetutorial.net/sqlite-functions/sqlite-trim/, I was finalized with the query below.

    SELECT 
        COUNT(*) FILTER (WHERE TRIM(q1) = '') AS empty_q1,
        COUNT(*) FILTER (WHERE TRIM(q2) = '') AS empty_q2,
        COUNT(*) FILTER (WHERE TRIM(q3) = '') AS empty_q3,
        COUNT(*) FILTER (WHERE TRIM(q4) = '') AS empty_q4,
        COUNT(*) FILTER (WHERE TRIM(q5) = '') AS empty_q5
    FROM assignment3;

In which the result was 3|3|4|4|4.

    function analyzeSubmissionsDB(db, table) {
        var analysis = {};

        analysis.count = db.query("SELECT COUNT(*) FROM " + table);
        analysis.studentIDList =

        analysis.emptyAnswers = db.query(`
            SELECT

                COUNT(*) FILTER (WHERE TRIM(q2) = '') AS empty_q2,
                COUNT(*) FILTER (WHERE TRIM(q3) = '') AS empty_q3,
                COUNT(*) FILTER (WHERE TRIM(q4) = '') AS empty_q4,
                COUNT(*) FILTER (WHERE TRIM(q5) = '') AS empty_q5

        `)
